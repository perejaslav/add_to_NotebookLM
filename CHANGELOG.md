# Изменения

Все заметные изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru-RU/1.1.0/),
версионирование соответствует [SemVer](https://semver.org/ru/).

## [1.2.0] — 2026-07-03

### Добавлено

- **Добавление выделенного текста** — пункт контекстного меню «Добавить выделение в NotebookLM» при выделении текста на любой странице
- Модуль `lib/selection-to-source.js`: нормализация, валидация, сборка payload с метаданными
- Настройки выделения: включение/выключение, минимальная и максимальная длина символов, добавление метаданных страницы
- Уведомления через `chrome.notifications` об успехе/ошибке
- Защита от двойной отправки (debounce 5 секунд для того же текста и нотбука)
- Нормализация значений min/max из storage (защита от повреждённых данных)
- Серийная пересборка контекстного меню (защита от гонок)
- Self-check модуля `selection-to-source.js` с throw-based проверками
- Секция «О проекте / About» в README (RU)

### Изменено

- Версия расширения: `1.1.0` → `1.2.0`
- `manifest.json`: добавлен permission `notifications`
- `background.js`: `importScripts` подключает `selection-to-source.js`
- Контекстное меню пересоздаётся через очередь `scheduleContextMenusRebuild()` вместо прямых вызовов
- README обновлён: описание выделения, секция «О проекте», crédиты

### Исправлено

- Версия `v1.1.0` в `app/app.html` → `v1.2.0`

## [1.1.0] — начальная версия

### Добавлено

- Добавление текущей страницы в нотбук одним кликом
- Захват страницы как PDF через Chrome Debugger API
- Добавление видео, плейлистов и каналов YouTube
- Парсинг комментариев YouTube (InnerTube API)
- Массовый импорт ссылок и вкладок
- Массовое удаление источников из нотбука
- Синхронизация Google Drive-источников (Docs, Sheets)
- Создание новых нотбуков из расширения
- Поддержка нескольких Google-аккаунтов
- Тёмная тема
- Русский и английский интерфейс
