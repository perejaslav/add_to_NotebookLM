# Изменения

Все заметные изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru-RU/1.1.0/),
версионирование соответствует [SemVer](https://semver.org/ru/).

## [1.3.1] — 2026-08-01

### Переименовано

- Пользовательское название расширения окончательно изменено с прежнего бренда на **Add to Gemini Notebook**
- Обновлены названия в русском и английском интерфейсе, контекстном меню, уведомлениях и подсказках
- Content script `content/notebooklm.js` переименован в `content/gemini-notebook.js`

### Изменено

- Версия расширения: `1.3.0` → `1.3.1`
- README и описание проекта приведены к актуальному бренду Gemini Notebook
- CI и релизная сборка обновлены для версии 1.3.1
- Имя установочного архива: `add_to_Gemini_Notebook-1.3.1.zip`

### Исправлено

- Удалены устаревшие пользовательские упоминания прежнего названия из локализаций и интерфейсных файлов
- Версия в дополнительных страницах расширения синхронизирована с `manifest.json`

### Совместимость

- Сетевая совместимость с прежними доменами Google сохранена; они используются только как технические legacy-адреса
- Все функции версии 1.3.0 сохранены без изменения поведения

## [1.3.0] — 2026-08-01

### Добавлено

- Поддержка нового домена Gemini Notebook `notebook.google.com`
- Поддержка Google Workspace-домена `notebook.cloud.google.com`
- Обратная совместимость со старыми доменами `notebooklm.google.com` и `notebooklm.cloud.google.com`
- Новый входной файл service worker `background-entry.js`
- Слой совместимости `lib/gemini-notebook-compat.js`, загружаемый до основной логики расширения
- Автоматическое запоминание фактического домена отдельно для каждого значения `authuser`
- Проверка обязательного наличия файлов слоя совместимости в GitHub Actions

### Изменено

- Название версии в манифесте: `Add to NotebookLM` → `Add to Gemini Notebook`
- Версия расширения: `1.2.0` → `1.3.0`
- Service worker теперь запускается через `background-entry.js`, который затем подключает существующий `background.js`
- RPC-запросы и загрузка PDF направляются на домен активного Google-аккаунта
- Ручное перенаправление при получении токенов заменяется на следование перенаправлению Google
- Имя релизного архива изменено на `add_to_Gemini_Notebook-1.3.0.zip`
- README полностью обновлён под текущее название, домены, установку, возможности и архитектуру версии 1.3.0
- README снова содержит полноценные русскую и английскую секции

### Исправлено

- Расширение снова работает для аккаунтов, перенаправленных с NotebookLM на Gemini Notebook
- Исправлена ложная ошибка авторизации, возникавшая из-за opaque redirect при `redirect: manual`
- Исправлены RPC- и PDF-запросы, которые ранее продолжали обращаться к устаревшему домену
- Исправлена работа content script на новых доменах Gemini Notebook
- Исправлены разрешения Manifest V3 для обычных и Workspace-аккаунтов

### Совместимость с 1.2.0

Все функции версии 1.2.0 сохранены. В частности, продолжает работать добавление выделенного текста через контекстное меню, настройки длины и метаданных, уведомления и защита от повторной отправки.

## [1.2.0] — 2026-07-03

### Добавлено

- **Добавление выделенного текста** — пункт контекстного меню «Добавить выделение в NotebookLM» при выделении текста на любой странице
- Модуль `lib/selection-to-source.js`: нормализация, валидация, сборка payload с метаданными
- Настройки выделения: включение/выключение, минимальная и максимальная длина символов, добавление метаданных страницы
- Уведомления через `chrome.notifications` об успехе/ошибке
- Защита от двойной отправки (debounce 5 секунд для того же текста и нотбука)
- Нормализация значений min/max из storage (защита от повреждённых данных)
- Серийная пересборка контекстного меню (защита от гонок)
- Self-check модуля `selection-to-source.js` с throw-based проверками
- Секция «О проекте / About» в README

### Изменено

- Версия расширения: `1.1.0` → `1.2.0`
- `manifest.json`: добавлен permission `notifications`
- `background.js`: `importScripts` подключает `selection-to-source.js`
- Контекстное меню пересоздаётся через очередь `scheduleContextMenusRebuild()` вместо прямых вызовов
- README обновлён: описание выделения, секция «О проекте», кредиты

### Исправлено

- Версия `v1.1.0` в `app/app.html` → `v1.2.0`

## [1.1.0] — начальная версия

### Добавлено

- Добавление текущей страницы в нотбук одним кликом
- Захват страницы как PDF через Chrome Debugger API
- Добавление видео, плейлистов и каналов YouTube
- Парсинг комментариев YouTube (InnerTube API)
- Массовый импорт ссылок и вкладок
- Массовое удаление источников из нотбука
- Синхронизация Google Drive-источников (Docs, Sheets)
- Создание новых нотбуков из расширения
- Поддержка нескольких Google-аккаунтов
- Тёмная тема
- Русский и английский интерфейс
